# Game List

**Game List** é um projeto desenvolvido como parte de um desafio proposto pelo professor **Julio César**, da Escola DNC, durante uma competição amistosa entre os alunos. O objetivo foi exercitar a criatividade e aplicar na prática os conhecimentos adquiridos ao longo da formação.

## Funcionalidades

- **Pesquisa por Nome**: Os usuários podem buscar jogos pelo nome.
- **Detalhes do Jogo**: Informações completas sobre cada jogo, como descrição, classificação, plataforma e data de lançamento.
- **Comentários**: Os usuários podem adicionar comentários aos jogos.
- **Visualização de Comentários**: Também é possível visualizar comentários feitos por outros usuários.

## 💻 Tecnologias Utilizadas

- **Frontend**: React
- **Backend**: Node.js + Express.js
- **Banco de Dados**: MongoDB
- **ORM**: Mongoose
- **Documentação da API**: Swagger
- **Estilo**: Sass
- **Roteamento**: React Router DOM
- **Requisições HTTP**: Axios
